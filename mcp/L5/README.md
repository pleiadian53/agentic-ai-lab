# Lesson 5: Creating an MCP Client

This lesson builds an MCP client that connects the chatbot from L3 to the MCP server from L4, making the chatbot MCP-compatible.

## Overview

The lesson demonstrates:

- **MCP Client architecture**: Connecting to servers via `ClientSession`
- **Tool discovery**: Dynamically listing tools from the server
- **Tool invocation**: Calling server tools through the client session
- **Async Python**: Using `async`/`await` for non-blocking I/O

## Prerequisites

- Python 3.10+
- Node.js (for uv/npx)
- Completed L3 (chatbot) and L4 (MCP server)
- Dependencies: `mcp`, `anthropic`, `python-dotenv`, `nest_asyncio`

## Key Concepts

### MCP Client Connection

```python
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

server_params = StdioServerParameters(
    command="python",  # or "uv"
    args=["research_server.py"],
)

async with stdio_client(server_params) as (read, write):
    async with ClientSession(read, write) as session:
        await session.initialize()
        tools = await session.list_tools()
        # ... use the session
```

### Tool Discovery

The client dynamically discovers tools from the server:

```python
response = await session.list_tools()
self.available_tools = [{
    "name": tool.name,
    "description": tool.description,
    "input_schema": tool.inputSchema
} for tool in response.tools]
```

### Tool Invocation

Instead of calling tools directly, the client delegates to the server:

```python
# Before (L3): Direct function call
result = execute_tool(tool_name, tool_args)

# After (L5): Via MCP session
result = await self.session.call_tool(tool_name, arguments=tool_args)
```
