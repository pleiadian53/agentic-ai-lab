# Lesson 4: Creating an MCP Server

This lesson wraps the chatbot tools from L3 into an MCP server using FastMCP, enabling them to be exposed via the Model Context Protocol.

## Overview

The lesson demonstrates:

- **FastMCP framework**: High-level interface for building MCP servers
- **Tool decoration**: Using `@mcp.tool()` to expose Python functions
- **stdio transport**: Running the server locally for testing
- **MCP Inspector**: Interactive tool for debugging MCP servers

## Prerequisites

- Python 3.10+
- Node.js (for MCP Inspector)
- Dependencies: `mcp`, `arxiv`
- Completed L3 (understanding of tool definitions)

## Quick Start (Local)

1. Generate the server file by running the `%%writefile` cell in the notebook

2. Launch the Inspector:

   ```bash
   cd /Users/pleiadian53/work/agentic-ai-lab/mcp/L4/mcp_project
   mamba activate agentic-ai
   npx @modelcontextprotocol/inspector python research_server.py
   ```

3. Open the Inspector UI at `http://localhost:6274`

4. Click **Connect** and test the tools

### Two Approaches to MCP Servers

| Approach | Description |
|----------|-------------|
| **Low-level** | Directly handle `ListToolsRequest` and `CallToolRequest` |
