# docs/products/ — Product Documentation

This directory holds **shareable documentation for graduated products** — applications
that have reached sufficient stability and completeness to be treated as products rather
than active experiments.

## What Belongs Here

A product document should:
- Describe a complete, usable feature set
- Include installation, configuration, and usage guides
- Be stable enough not to change every week
- Be written for end users, not just developers

## Lifecycle

```
docs/applications/<app>/  ← development-phase docs
        ↓ (on graduation)
docs/products/<app>/      ← this directory
```
